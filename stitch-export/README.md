How to export from Stitch:

1. Open the project at https://stitch.withgoogle.com/projects/4590429823157632396
2. Select a screen.
3. Use the **Code** / **Copy code** action (Stitch outputs HTML + Tailwind classes).
4. Save it here with the matching name above.
